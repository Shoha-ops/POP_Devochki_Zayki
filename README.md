# ANIVERY

C++ console marketplace project for an OOP course by the team tobaskA+. The application supports users, shops, products, carts, favorites, orders, payments, and administrator workflows.

## Features

- User registration, login, profile editing, cart, favorites, orders, and payment history
- Shop registration with admin approval
- Shop product management and order status management
- Admin and head admin panels
- Text-file persistence for project data

## Data Files

The app stores data in:

- `users.txt`
- `shops.txt`
- `products.txt`
- `cart.txt`
- `favorites.txt`
- `orders.txt`
- `payments.txt`
- `admins.txt`

These files are local runtime data and are ignored by git.
